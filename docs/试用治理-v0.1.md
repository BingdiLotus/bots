## 5. 事件与回滚

**unknown**：暂停 Bot → 原 thread 核对 → 保留 delivery/task/audit ID → resolve confirmed/rejected → 记录；不新建 delivery 重发。

**rejected/权限**：检查 bot 是否在频道/账号是否 disabled → 修复权限 → 新消息重试，不复用旧 delivery。

**readiness/模型**：连续失败 >5 分钟或模型失败率 >5% → 暂停扩量；无法恢复则回滚。

**回滚**：
- 当前 release：`bingdi-bots:mvp-20261021-metrics`，digest `sha256:9b3dfac7…`；
- 上一镜像：`bingdi-bots:mvp-20261021`，digest `sha256:e9c7958b…`；
- 回滚只切换镜像并重启 `bots-trial`，保留 PG/Chronotope 数据；不执行 `down -v`；
- seed/env 不变；回滚后跑 `/readyz` + `trial-health.sh`；
- 回滚 owner：trial owner；技术执行：Bots maintainer。

触发回滚：unknown 超 1 个工作日未收口、rejected 重复、readiness 5 分钟 <99%、严重错误回答或 owner 判断。
