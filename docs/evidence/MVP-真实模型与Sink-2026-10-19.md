- 恢复后发送一次确定性提醒；Task completed、delivery confirmed 和审计落账，不需要新模型调用。
- 重启后的新 thread 使用新 runtime session，通过 recall 读取原知识及来源；两轮模型完成该请求，总 LLM call count 为 **4**。
