|---|---|
| 同一签名消息重投十次 | 1 个输入、1 次 run、1 条知识、1 个提醒槽、1 次最终回复 |
| 一轮 remember + create_reminder | 两个原 call ID 及真实结果进入下一模型 HTTP 请求，实际随机 knowledge ID 被回显；五工具 schema/description 与 token 上限被检查 |

| 重启后的新 thread | 新 runtime session recall 相同的内化知识及来源；总共 2 次 run、4 次模型 HTTP 请求 |
