# 2-Bot 真 Slack 实验室：2026-10-20

这是 test-only 实验，不是 MVP 多 Bot 产品能力。MVP 范围仍是一 Bot、一 Slack 账号、一模型；本实验验证两个独立 harness/tenant 的 Slack 身份、路由、peer mention 和故障边界。

## 环境

| 项 | Lab A | Lab B |
|---|---|---|
| Slack 频道 | `#bingdi-bots-lab` | 同频道 |
| Slack app | 现有 `REDACTED_APP_A` | 新建 `REDACTED_APP_B` |
| Slack bot user | `REDACTED_BOT_USER_A` | `REDACTED_BOT_USER_B` |
| Bots tenant/bot | `bots-lab-a` / `bingdi-a` | `bots-lab-b` / `bingdi-b` |
| 容器/端口 | `bots-lab-a` / 8091 | `bots-lab-b` / 8092 |
| Chronotope agent | `a_042343e5…` | `a_fd2a43e9…` |
| peer allowlist | 允许 B 的 bot ID | 允许 A 的 bot ID |

两个容器均为 `read-only`、65532、`no-new-privileges`、`--restart unless-stopped`，`/readyz` 200、Socket Mode connected。Trial 容器暂停，旧 bot/revision 2/trial 数据保留；Lab A 复用现有 app，Lab B 用新 app。

## Peer bot 开关

`f151e72` 增加 env-only `BOTS_TEST_ALLOWED_BOT_IDS`。只允许 allowlist 中 peer bot 的**显式 app_mention**；自身消息、普通 bot 消息、thread reply、编辑/删除仍过滤，默认空。启动时打印 `test-only peer bot allowlist enabled` 警告。它不是 seed/config/API 字段。

## Loop budget 与自动多轮驱动器

`9432ab0` 增加 `BOTS_TEST_MAX_PEER_ROUNDS`；`test/lab/drive.py` 用 Lab B 身份发一条顶层 @A，再在同一 thread 追加 peer 尝试，每轮观察 A inbox 增长。

2026-10-20 实测：budget=2，driver 3 次尝试：

| 项 | 结果 |
|---|---|
| driver 初始消息 | ts `1792536454.982949`，A inbox +1 |
| driver 第 2 次尝试 | ts `1792536457.360179`，A inbox +1（达到 budget） |
| driver 第 3 次尝试 | ts `1792536459.756019`，A inbox 不增，被截断 |
| A/B 最终 inbox delta | +2 / +1 |
| final deliveries | A confirmed `1792536461.650909`、`1792536467.628319`；B confirmed `1792536468.871769` |
| unknown/循环 | 0 unknown；无新 A run |

这验证了自动多轮 seed + per-bot/thread 截断；budget 不是跨进程全局计数器，重启会清零。

## 边界与待修

- 只验证了**显式 app_mention** 链路；B 的首次回复因为 Slack transport 未送达，不是 allowlist/路由失败。bot-to-bot thread reply 仍默认过滤。
- Loop budget 为**进程内、per bot/thread**，重启清零；不是全局共享预算。`test/lab/drive.py` 的 attempts 与 bot instructions 共同控制轮数。
- 新 app `REDACTED_APP_B` 当前 bot token 实际 12 个 scopes（`im:*`、`reactions:*`、`users:read`、`assistant:write` 等），不是 manifest 的 4 个。Slack CLI `apps.status` 当前 EOF，未能自动 sync；**test-only、勿用于生产**，在扩大 lab 前用 Slack UI/重新登录 CLI 收紧并重装。
- Trial 仍暂停；Lab A 复用其 app token，不能与 trial 同时运行。结束 lab 时停 Lab A、恢复 trial。
- AI 小分队不能替代真人团队对信任、歧义、采纳的验证；本实验只覆盖合成多 Bot 行为。
